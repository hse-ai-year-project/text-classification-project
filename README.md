## План работы


### 1. Старт и планирование

**Дедлайн: 6 октября**

- Чат с куратором, знакомство
- Фиксация темы и плана на год
- Выбор датасета
- GitHub-репозиторий + README (тема, команда, куратор, план)
- Ссылка в peer-reviewer и куратору

### 2. Разведочный анализ данных (EDA) и предобработка данных

**Дедлайн: 27 октября**

- Загрузка и первичный осмотр данных
- Предобработка данных - чистка, токенизация, лемматизация
- Баланс классов, длины текстов, частотные слова
- Визуализации: barplot классов, гистограммы длин, wordcloud
- Выводы EDA

### 3. Первые ML-модели

**Дедлайн: 27 ноября**

- Выбор метрики (F1-macro, Accuracy, confusion matrix)
- Векторизация текста TF-IDF (TF-IDF с n-граммами)
- Построение Baseline моделей: Naive Bayes, Logistic Regression, SVM
- Сравнение моделей, таблица метрик

### 4. ML-сервис (FastAPI)

**Дедлайн: 15 декабря** _(также ДЗ по «Инструментам разработки»)_

- Сохранение модели и векторизатора
- FastAPI-сервис
- Docker


### 5. Улучшение ML-модели

**Дедлайн: 15 марта**

- Feature engineering: Word2Vec vs TF-IDF
- Feature selection (chi2, mutual information)
- Char n-граммы, ансамбли
- Анализ типичных ошибок

### 6. Нейронные сети

**Дедлайн: 5 мая**

- MLP на TF-IDF и Word2Vec
- Sentence-transformers как фичи + LogReg/SVM
- Сравнение: TF-IDF vs Word2Vec vs sentence-transformers
- Выводы о приросте от DL

### 7. Финальные доработки

**Дедлайн: ~начало июня**

- MLflow: логирование экспериментов
- Воспроизводимость: seed, requirements
- Переобучение лучшей модели
- Финальный анализ ошибок и устойчивости
- Тест на новых примерах
